## 📌 Git Workflow

For every meaningful update:

```bash
git status
```

Check what has changed.

```bash
git add .
```

Stage the changes.

```bash
git commit -m "Describe what you changed"
```

Create a checkpoint.

```bash
git push
```

Upload the changes to GitHub.

### Example

```bash
git add .
git commit -m "Practice Python functions and arguments"
git push
```
